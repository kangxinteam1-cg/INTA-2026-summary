145 个司法管辖区覆盖 6 大洲：欧洲（EU 27 国 + EFTA + Brexit 后 UK + 巴尔干 + 俄白等）、北美（US + CA + 墨西哥 + 加勒比）、亚太（含中东欧亚一带 + ASEAN10 + 大洋洲 + 日韩印中）、拉美（巴西 / 阿根廷 / 智利 / 哥伦比亚 / 秘鲁等）、非洲（南非 / 尼日利亚 / 肯尼亚 + OAPI 17 国法语区）、中东（GCC 6 国 + 以色列 + 土耳其）。

对康信的判断 —— 145 这个数字意味着欧洲 + 中东 + 非洲的"周边司法体系"代表都到场了。这是康信的OAPI / GCC / Israel / Turkey 涉外业务最容易在 INTA 现场对接到当地代理的窗口。

CORPORATE ORGANIZATIONS

507 家不同企业 · 平均每家派出 1.74 人

企业数 INTA 披露 L1 · 哑铃结构观察为康信团队整理

507

882 位企业法务 ÷ 507 家企业 ≈ 每家平均 1.74 人 L1。背后是典型的"哑铃结构"——

  • 头部跨国企业（Apple / Amazon / Microsoft / Tencent 等）派出 5-10 人专项 IP 团；
  • 中型企业（消费品 / 制药 / 工业）派出 2-3 人，覆盖商标 + 专利 + 反假冒；
  • 大量中小企业仅派 IP 负责人单人参会 —— 这部分是最容易在展位前停下来对话的目标人群。
动作建议 —— 会后名片回流时，按"单人参会" vs "团队参会"做分层标记。单人到场的中小企业 IP 负责人，是康信 SaaS 平台 + 标准化服务的最佳 PMF 客户。
